## Problem

Showing my projects to recruiters without the showcase itself becoming a risk, at a time when AI-related and software supply-chain breaches are multiplying.

## Solution

A bilingual static site generated by Hugo: each project is a plain text file, checked automatically before publishing. The site is designed and built with an AI coding assistant, framed by a specification, tests and a security review.

## Risks & safeguards

- **Software supply chain** → a single build tool with no npm dependencies; pinned versions verified by checksum.
- **Code injection (XSS)** → no JavaScript, and a security policy (CSP) that forbids any script.
- **Data exposure** → no forms, cookies or trackers; no internal data published, backed by an automated check.
- **AI-written code** → every step is tested before it is accepted, then the whole is reviewed.

## Outcome

Site finished and tested locally; Swiss hosting coming next.
