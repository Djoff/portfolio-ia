## Problem

Running several 3D printers takes constant monitoring and a lot of manual work: picking up each request, preparing the files, starting the prints and checking that they go well.

## Solution

Connect online requests to production: files are prepared automatically, production is scheduled across the printers, then monitored by camera and other sensors. The system relies on open-source tools (Klipper, Moonraker, OrcaSlicer) and is built with Claude Code.
