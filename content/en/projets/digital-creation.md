## Problem

Having an AI build a full application, with an interface and a server, while keeping it secure and fast. This is far more demanding than a static site like this one: accounts, data, interactions between users.

## Solution

A site where anyone can make ephemeral art pieces, with no purpose other than the joy of creating, alone or together. The project is a playground for experiments: the application is built with Claude Code, and the other tools are still to be chosen.
